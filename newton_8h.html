Подробное описание

Вариант 4: первое приближение корня методом Ньютона (касательных).

Автор
Далаков Аслан, 251-952

Функция задаётся многочленом третьей степени f(x) = c3*x^3 + c2*x^2 + c1*x + c0, её производная f'(x) = 3*c3*x^2 + 2*c2*x + c1 вычисляется аналитически.

Первое приближение считается по формуле

\[ x_1 = x_0 - \frac{f(x_0)}{f'(x_0)} \]
