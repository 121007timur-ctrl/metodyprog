# Тест-кейсы: Элементы списка

**Приоритет:** 1  
**Область:** Элементы списка  
**Всего тест-кейсов:** 3

---

## TC-101: Добавление элемента в список

| Поле | Значение |
|------|----------|
| Предусловие | Список пуст |
| Шаги | 1. Ввести текст «Тест» в поле ввода<br>2. Нажать «Добавить» |
| Ожидаемый результат | В списке появляется элемент «Тест» |
| Статус | ⬜ Не выполнен |

---

## TC-102: Удаление элемента из списка

| Поле | Значение |
|------|----------|
| Предусловие | В списке есть элемент «Тест» |
| Шаги | 1. Выделить элемент «Тест»<br>2. Нажать «Удалить» |
| Ожидаемый результат | Элемент «Тест» исчезает из списка |
| Статус | ⬜ Не выполнен |

---

## TC-103: Редактирование элемента

| Поле | Значение |
|------|----------|
| Предусловие | В списке есть элемент «Старый текст» |
| Шаги | 1. Дважды кликнуть по элементу<br>2. Изменить на «Новый текст»<br>3. Нажать Enter |
| Ожидаемый результат | Элемент меняется на «Новый текст» |
| Статус | ⬜ Не выполнен |
