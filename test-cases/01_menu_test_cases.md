# Тест-кейсы: Меню + кнопки

**Приоритет:** 2  
**Область:** Меню и кнопки управления  

## TC-001: Проверка меню «Файл»

| Поле | Значение |
|------|----------|
| Предусловие | TextFilter запущен |
| Шаги | 1. Нажать на меню «Файл»<br>2. Проверить пункты: Открыть, Сохранить, Выход |
| Ожидаемый результат | Открывается выпадающее меню, все пункты активны |
| Статус | ⬜ Не выполнен |

## TC-002: Проверка горячих клавиш

| Поле | Значение |
|------|----------|
| Предусловие | TextFilter запущен |
| Шаги | 1. Нажать Ctrl+O<br>2. Нажать Ctrl+S<br>3. Нажать Alt+F4 |
| Ожидаемый результат | Горячие клавиши работают |
| Статус | ⬜ Не выполнен |

## TC-003: Проверка стрелок навигации

| Поле | Значение |
|------|----------|
| Предусловие | В списке есть 3+ элемента |
| Шаги | 1. Нажать стрелку вниз 2 раза<br>2. Нажать стрелку вверх 1 раз |
| Ожидаемый результат | Выделение перемещается по элементам списка |
| Статус | ⬜ Не выполнен |

## TC-004: Проверка кнопок управления

| Поле | Значение |
|------|----------|
| Предусловие | TextFilter запущен |
| Шаги | 1. Нажать кнопку «Добавить»<br>2. Нажать кнопку «Удалить»<br>3. Нажать кнопку «Очистить» |
